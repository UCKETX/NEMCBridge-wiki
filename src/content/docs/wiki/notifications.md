自 **`v1.6.1`** 起，NEMCBridge 控制台新增独立的 **「通知」** 管理页，支持把房间动态、玩家上下线、国际服健康状态与好友申请实时推送到玩家群或服主个人设备。

所有通知通道彼此解耦，**新增、编辑、启停通道都会即时生效，无需停止正在运行的房间**；投递在后台异步队列中执行，不会阻塞开房保活或玩家转发。

## 典型分流场景

你可以按接收对象创建多个独立通道，互不干扰：

- **玩家群播报通道**（OneBot QQ 群 / Discord / 飞书 / 钉钉 / 企业微信）：勾选「房间启动 / 房间号变化 / 房间停止」，可选开启「同步维护 QQ 群公告」与「包含房间密码」，不暴露玩家真实 IP。
- **服主私密告警通道**（Bark / Telegram / OneBot 私聊）：勾选「国际服离线/恢复 / 开房连续异常告警 / 房间满员 / 新好友申请」，可按需开启「附带玩家真实 IP」与 Bark 30 秒告警响铃。

## 支持的 8 大平台与专属能力

在控制台粘贴平台链接时会自动识别对应预设，并给出官方机器人申请入口：

| 平台 | 适用场景 | 必填项 | 平台专属能力 |
| --- | --- | --- | --- |
| **OneBot v11** | QQ 群 / QQ 私聊（NapCat、LLOneBot、Lagrange 等） | OneBot HTTP 地址 + QQ 群号 / QQ 号 | 群模式支持 `@全体` / `@指定 QQ`、**同步维护 QQ 群公告**；可选 Bearer Token 鉴权 |
| **飞书 / Lark** | 飞书群自定义机器人 | Webhook 地址 | 彩色交互卡片、HMAC 签名校验、`@所有人` / `@open_id` |
| **钉钉** | 钉钉群自定义机器人 | Webhook 地址 | Markdown 排版、加签（`SEC...`）、`@所有人` / `@手机号` |
| **企业微信** | 企业微信群机器人 | Webhook 地址 | Markdown 排版，免密钥开箱即用 |
| **Discord** | Discord 文字频道 Webhook | Webhook 地址 | 彩色 Embed 卡片、顶层 `@everyone` / `@here` / `@角色ID` / `<@用户ID>` 提醒 |
| **Telegram** | Telegram Bot（支持自建反代） | Bot API 地址 + Chat ID | HTML 排版、`<code>` 房间号/密码点击即复制、超级群话题 ID（`message_thread_id`）、静默推送（`disable_notification`） |
| **Bark（iOS）** | iPhone / iPad 强提醒 | 设备推送地址（支持自建） | 开房/换号下拉一键复制房间号、离线/异常自动时效性通知（`timeSensitive`）、自定义铃声、自定义图标、告警持续响铃 30 秒 |
| **通用 JSON** | 自建服务 / n8n / Worker | Webhook 地址 | 完整结构化 JSON、自定义 HTTP Header（最多 10 个）、`X-NEMCBridge-Signature-256`（HMAC-SHA256 签名） |

## 触发事件与选服大厅路由规则

每个通道可独立选择「全部国际服（含后续新增）」或「仅指定国际服」，并按需勾选以下 8 类事件：

| 事件 | 触发时机 |
| --- | --- |
| **房间启动** | 首次开房上线并拿到房间号 |
| **房间停止** | 手动停房、关服或异常退出 |
| **房间号变化** | 掉线自动重连并分配到新房间号 |
| **国际服离线 / 恢复** | 国际服连续 2 次探测无响应，或从离线恢复在线 |
| **开房连续异常告警** | 连续 3 次开房或鉴权失败 |
| **玩家加入 / 离开** | 玩家实际进入或离开目标国际服（`[+] 玩家 加入了 服名` / `[-] 玩家 离开了 服名`） |
| **房间人数已满** | 满员拒入提醒（带 5 分钟冷却防刷屏） |
| **新好友申请** | 收到待审好友申请或已自动同意 |

### 选服大厅智能去重
当房间绑定了[选服大厅](../backends-and-gateway/#选服大厅)（例如「主大厅」包含「樱花庄」和「粘液科技」）时：
- **房间级事件**（开房、换号、停房、满员、异常告警、好友申请）：按通道自动去重——同一个通道即使勾选了大厅内的多个服或「全部国际服」也**只推送 1 次**；而分别绑定到不同 QQ 群的两个独立通道会**各自收到 1 次**，不会漏发，且标题自动显示**选服大厅名称**。
- **单服级事件**（玩家加入/离开、国际服离线/恢复）：严格按玩家实际选中的单个服或被探测的单个服路由，不串群、不重复。

## QQ 群公告实时维护（OneBot 群）

在 OneBot 群通道勾选 **「同步维护 QQ 群公告（房间号实时更新）」** 后（需确保机器人账号为群管理员）：

1. **只维护唯一一条最新公告**：由于 QQ / OneBot v11 协议本身没有原生「原地编辑公告」接口，NEMCBridge 首次开房会发布新公告，后续开房、换号或停房时会自动发布最新公告并调用 `/_get_group_notice` + `/_del_group_notice` 删除本程序上一次发出的旧公告。
2. **绝不误删管理员公告**：本程序发出的 `notice_id` 与正文签名持久化保存在数据目录的 `onebot_notices.json` 中，重启后依然准确替换自己的公告，群主或管理员手动发布的群规等公告不会被触碰。
3. **多服同群自动合并**：无论单个通道选了多服，还是多个通道指向同一个 QQ 群，都会按 `(OneBot 地址, 群号)` 自动聚合并维护**唯一一条**包含所有在线房间号的群公告；同一服务器多开账号时也会合并展示。

### 群公告模板与按服名拆开插槽

勾选同步群公告后即可直接编辑预填的默认模板并实时预览：

- **通用变量**：`{{rooms}}`（自动列出该群全部在线房间）、`{{room_id}}`、`{{room_password}}`、`{{server_name}}`、`{{online_count}}`、`{{updated_at}}`。
- **按服名 / 大厅名精准插槽**：希望在公告不同段落分别展示各个服的房间号时，可使用 `{{room_id:服务器名或大厅名}}` 与 `{{room_password:服务器名或大厅名}}`（控制台变量栏会自动为每个已配置的国际服和选服大厅生成一键插入按钮）：

```text
🎮 欢迎来到方块小站！

🌸 樱花庄（纯净生存）
房间号：{{room_id:樱花庄}}

🧪 粘液科技（工业养老）
房间号：{{room_id:粘液科技}}  密码：{{room_password:粘液科技}}

🕒 更新时间：{{updated_at}}
```

- 对应服尚未开房时，`{{room_id:服名}}` 会自动显示 `暂未开房`；同一服多开多个房间时自动用 ` / ` 拼接（如 `302994 / 305118`）；选服大厅既支持填大厅名也支持填子服名。

## 按事件分别自定义消息模板

展开通道编辑弹窗底部的 **「自定义消息模板」**，可按 **10 类具体事件**（房间启动、房间号变化、房间停止、国际服离线、国际服恢复、异常告警、玩家加入、玩家离开、房间满员、好友申请）分别修改文案：

- 每个事件默认预填对应的内置模板，直接修改即可，点击「恢复默认」可随时还原；未改动的事件保持平台原生富文本排版。
- 切换事件标签时，变量快捷按钮和下方「实时预览」会自动切换为该事件实际可用的变量。
- **测试通知**始终固定为简洁单行（`✨ [测试] 通道「名称」配置正常，通知可正常送达。`），不受自定义事件模板或房间密码开关影响。

## 隐私保护与推送记录排查

- **隐私开关默认关闭**：房间密码与玩家真实 IP 均默认不附带，且按通道独立控制，避免误发到公开玩家群。
- **日志与状态脱敏**：`logs/status.json` 与运行日志会自动脱敏 Webhook 链接中的 Token、加签密钥与自定义请求头。
- **推送记录弹窗**：点击「通知」页右上角 **「推送记录」** 按钮可查看本次运行最近 30 条投递结果、耗时与完整报错信息，并支持一键筛选「仅失败」；有失败记录时角标会自动标红提示。

| 常见问题 | 排查建议 |
| --- | --- |
| 测试通知提示平台返回错误 | 检查 Webhook 地址、签名密钥、目标群号 / Chat ID 是否完整；钉钉需勾选「加签」安全设置，OneBot 需确认 HTTP 端口与 Access Token 正确 |
| QQ 群消息正常，但群公告未更新 | 确认机器人账号具备群主或群管理员权限，且所用的 OneBot 实现（如 NapCat / LLOneBot）已启用 `_send_group_notice` / `_get_group_notice` / `_del_group_notice` |
| Telegram 超时或连接失败 | 国内网络无法直连 `api.telegram.org`，请在 Telegram 地址栏改填自建反代域名（格式 `https://你的反代/bot<TOKEN>/sendMessage`） |
