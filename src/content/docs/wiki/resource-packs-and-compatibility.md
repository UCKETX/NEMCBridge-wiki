本页合并说明两件最容易踩坑的事：**资源包与 4D 皮肤如何加载**，以及**哪些 Bedrock 后端版本和服务端实现可以接入**。

## 适用版本与前置条件

- **适用版本**：NEMCBridge `v1.5.5`。
- **网易侧基线**：网易客户端 `3.10.5.301327`，房间内核 `1.21.130.0`，网易侧游戏协议 `898`。
- **核心原则**：**房间版本与国际服后端版本相互独立**。桥接在每次连接时自动识别后端协议，**不要**把网易房间版本改成后端版本。国际版直连玩家仍须与后端版本一致；Java 版客户端无法直接连入 NEMCBridge，须经 Geyser 的 Bedrock 入口中转。

## 一、资源包与 4D 皮肤

### 先区分三类资源

| 资源类型 | 接收对象 | 服主是否需要手动安装 |
| --- | --- | --- |
| 桥接自动外观兼容包 | 仅网易桥接玩家（不下发给国际版直连） | **不需要**。桥接按后端协议自动下载、校验 SHA-256、缓存至 `cache/appearance/` 并下发。 |
| 服务器自制材质包 | 国际版直连与网易桥接玩家 | **需要**，按常规 BDS 世界配置安装。 |
| 国际版 4D 模型资源包 | 选择接受下载的国际版客户端 | **可选**，且须使用已适配的模型包；NEMCBridge 安装包不附带模型文件。 |

> 网易端默认使用内置组件完成预加载，**不会把经典材质加入实际加载栈**。无需在控制台额外勾选开关，也无需让玩家在手机上手动导入。旧配置中的 `forward_resource_packs: false` 会在升级时自动迁移为启用。

### 安装服务器自制材质包步骤

1. 将解压后的材质包目录放入 BDS 的 `resource_packs/`，确认目录第一层直接包含 `manifest.json`。
2. 在 `worlds/<level-name>/world_resource_packs.json` 的数组中追加对应的 `pack_id`（即 `header.uuid`）和 `version`（即 `header.version`）。每次更新包内容时，**同步提升 `manifest.json` 和世界引用中的版本号**。
3. 重启 BDS，**先用国际版直连**验证材质生效，再重开 NEMCBridge 房间让网易玩家重进检查（首次下载大包耗时较长，请等待完成）。
4. 若你曾手动配置过自定义网易组件预加载，可保留 `netease_resource_packs: true`；若怀疑旧配置导致经典材质混入加载栈，可改回 `false` 恢复默认内置流程。

### 4D 皮肤同步与边界（v1.5.1+）

- 普通桥接房间支持同步网易玩家原生 4D 装扮，并为已验证的 4D 外观提供国际版普通皮肤回退，避免透明占位。
- 若想让国际版看到特定已适配的 4D 模型，可按上述步骤将兼容 `.mcpack` 解压安装到 BDS，并在 `server.properties` 保持 `texturepack-required=false` 供国际版玩家自选下载。网易玩家进房会自动跳过该专用模型包 UUID，不影响其他后端材质。
- **已知边界**：不是所有商城 4D 模型都已适配；Geyser 场景的网易 4D 皮肤暂不在已修复范围内；国际版看不到普通皮肤时，先在客户端关闭「仅允许受信任的皮肤」再重进。

### 新版内容外观已知缺口

高版本后端（如 `26.60`）中的白杨、硫磺/朱砂、部分建筑变体与新增物品采用独立兼容外观或旧版替代，但仍有明确缺口：

- 白杨船放下后仍显示为白桦船体；稻草床可能短暂显示红床，行为不等同原生支持。
- 冰系实验内容、照片、唱片压制机界面不在当前支持范围内；层架蘑菇弹跳为近似补偿。
- 行为包、客户端脚本、复杂自定义 UI、PBR 光影与加密商城资源没有通用兼容保证。逐项状态见 [26.60 适配清单](https://github.com/UCKETX/NEMCBridge/blob/v1.5.5/docs/compatibility-status-26.60.md)。

## 二、BDS 协议兼容表

下表列出当前支持的 11 档后端协议及通过基础自动验证的官方 BDS 构建。**表外协议直接拒绝连接，无法通过修改 MOTD 或版本字符串绕过。**

| 协议号 | Bedrock 版本 | 已验证官方 BDS 构建 | 备注 |
| --- | --- | --- | --- |
| `859` | `1.21.120–1.21.123` | `1.21.123.2` | 实验性 |
| `860` | `1.21.124` | `1.21.124.2` | 实验性 |
| `898` | `1.21.130` | `1.21.130.4` | **推荐基线**，已通过网易 3.10 真实客户端验证 |
| `924` | `26.0–26.2` | `1.26.0.2`、`1.26.2.1` | 须启用哈希方块 ID |
| `944` | `26.10` | `1.26.10.4` | 离线身份返回空 XUID，注意权限复验 |
| `975` | `26.20` | `1.26.20.5` | 含网易安卓主要流程反馈；离线返回空 XUID |
| `1001` | `26.30` | `26.30.5` | RakNet 验证 |
| `2168` | `26.40` | `26.40.8` | RakNet 验证 |
| `2169` | `26.45` | `26.45.1` | RakNet 验证 |
| `2193` | `26.50` 系列 | `26.51.1` | 按 NetherNet 验证（`transport=nethernet`） |
| `2225` | `26.60` | `26.60.6` | 按 NetherNet 验证；含网易安卓主要流程反馈 |

> 多数跨版本组合以合成网易 898 客户端自动化回归为主，不代表同协议下所有补丁或全部玩法均已完成真实手机验收。

## 三、Geyser 与其他基岩服务端

### Geyser（实验性）

- **覆盖范围**：所列 `859–2225` 全部 11 档协议的原版顺序方块表均通过基础登录、区块、聊天与连续动作回归（`v1.5.5` 已修复 Geyser 暂停菜单重复显示自己的问题）。
- **必须满足的配置**：
  1. 关闭 `gameplay.enable-custom-content`（桥接仅支持匹配的原版顺序方块表，不支持自定义方块与区块 blob 缓存）。
  2. 支持该选项的构建须关闭 `advanced.bedrock.validate-bedrock-login`，并通过防火墙将该入口限制为仅允许可信桥接主机访问。
  3. 控制台填写 Geyser 的 **Bedrock 入口**（不填 Java TCP 端口）；Java 服务端无需添加 BDS 哈希方块配置。
  4. 若使用 NetherNet，确保 Geyser 的 WebRTC UDP 端口与信令声明地址均可从桥接主机直达。
- **验收边界**：以合成客户端回归为主，真实手机端的渲染、移动、挖放与骑乘仍需服主实测确认。

### 其他已测基岩服务端固定构建

| 协议 | 已测固定构建 | 特殊要求与已知限制 |
| --- | --- | --- |
| `1001` | Allay `0.14.0`、PocketMine-MP `5.44.3` | 已测构建不支持更高协议。 |
| `2225` | PowerNukkitX `3.0.6`、Nukkit snapshot `1252`、Nukkit-MOT `1766`、Cloudburst snapshot `162`、Dragonfly 受测构建 | Nukkit `2168+` 编码在 `v1.5.0+` 支持自动识别（如遇方块/物品错位，可在国际服设置中手动指定 `Nukkit` 兼容配置）。 |
| `2225` | Endstone `0.11.15` + BDS `26.60.6`、LeviLamina `26.60.4` + Windows BDS `26.60.6` | LeviLamina `924 (26.0)` 与 `2169 (26.45)` 无匹配官方组合未测；实验性验证不延伸到任意插件或模组。 |

## 成功标志

- 跨版本后端首次进房时，`cache/appearance/` 生成对应外观包缓存，网易玩家可见新版方块/物品的兼容外观，且国际版直连不受影响。
- 自制材质包在国际版与网易端均生效，重进世界不卡加载。
- 控制台日志正常识别后端协议号，无协议不支持或方块表冲突报错。

## 常见失败与排查

| 现象 | 优先检查项 |
| --- | --- |
| 资源包显示下载结束，但进游戏材质未生效 | 先用国际版直连确认世界配置中 UUID、版本号和依赖无误；更新材质后是否同步提升了版本号并重开房间；注意早期下载完成响应不等于渲染生效。 |
| 连接 Geyser 时断开或方块错乱 | 确认已关闭 `gameplay.enable-custom-content` 且未使用自定义方块/blob 缓存；确认填的是 Bedrock 入口而非 Java 端口。 |
| 国际版看不到网易玩家皮肤，或模型变透明 | 国际版关闭「仅允许受信任的皮肤」重进；若仅在启用某材质包后出现异常（如部分枪械包覆盖玩家渲染），先停用该包对照排查。 |
| 后端启动后桥接提示协议不支持 | 核对后端实际版本是否在上述 11 档协议内，且 `26.x` 已开启 `block-network-ids-are-hashes=true`。 |
